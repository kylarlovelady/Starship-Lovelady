# Offline brain (house computer that works with no internet)

Kylar's question (voice, 2026-11-06): if America were hit and the internet was down, could he host something like Claude at home, protected in a Faraday cage? Answer given: Claude itself cannot be hosted (a very large model on Anthropic's servers). A smaller open-source model can run fully offline on his own hardware.

- Pi 5 can run small models slowly. A mini PC with a lot of memory, or a computer with a good graphics card, runs bigger, smarter ones. Quality is well below Claude. Mini PC about $300 to $800 (rough, unchecked).
- The information matters more than the model: pair it with an offline library (Kiwix with Wikipedia, medical references, repair manuals, how-to guides) that a local model can search.
- Faraday storage: keep the machine and a second drive (library + backup of these memory notes) in a metal cabinet or large can; power it up only when needed.
- Status: idea, later project, after the Field Deck. Next step: research hardware and a starter library list.
